# ЧайАркан — chaiarkan.ru

Одностраничный сайт на React: посетитель передвигает звёзды на 12-лучевой «паутинке» вкуса
и получает своё уникальное созвездие и подходящий сорт китайского чая.

## Запуск

```bash
npm install
npm run dev      # локальная разработка, http://localhost:5173
npm run build    # production-сборка в папку dist/
npm run preview  # посмотреть собранную версию
```

Папка `dist/` уже содержит готовую сборку — её можно сразу выложить на любой статический хостинг
(nginx, Netlify, GitHub Pages, S3). `npm run build` пересоберёт её через Vite.

## Что внутри

```
src/
  App.jsx                 — состояние созвездия, анимации, ссылка «поделиться»
  components/
    FlavorWeb.jsx         — главный виджет: 12-лучевая паутинка с перетаскиванием вершин
    Oracle.jsx            — панель результата: имя созвездия, найденный сорт, соседние звёзды
    Sections.jsx          — свиток сорта, атлас нот, звёздный каталог, ритуал, шапка, подвал
    MiniRadar.jsx         — маленькая паутинка для карточек
    Starfield.jsx         — живое звёздное небо на canvas (мерцание, параллакс, метеоры)
  data/
    notes.js              — 12 нот вкуса: название, иероглиф, цвет, описание
    teas.js               — 25 китайских чаёв с профилями по 12 нотам и параметрами заваривания
  lib/constellation.js    — подбор чая, имя и код созвездия, кодирование в URL
  styles.css              — всё оформление
```

## Как работает виджет

- Вершину можно тянуть мышью, пальцем или стилусом (Pointer Events). Мышью можно схватить
  луч в любом месте паутинки; пальцем — тянуть звезду или просто тапнуть по лучу.
- Возле центра, где вершины соседних лучей почти слипаются, луч выбирается по направлению движения.
- С клавиатуры: Tab — к звезде, стрелки — ±0,5, PageUp/PageDown — ±2, Home/End — 0/10.
- Пунктирный контур — профиль найденного чая, чтобы видеть, насколько созвездия совпадают.
- Созвездие сохраняется в адресе (`?sky=…`), поэтому ссылкой можно поделиться.

## Предсказание и колода

Пока пользователь двигает звёзды, сорт не показывается. Кнопка «Получить предсказание» открывает колоду
(`src/components/Prediction.jsx`): карты тасуются, раздаются рубашкой вверх и переворачиваются.

- На большом экране вытягивается от 1 до 3 карт: лучшая всегда, ещё до двух, если их совпадение не более
  чем на 6 пунктов ниже лучшей и не ниже 70 %. На телефоне всегда одна карта.
- Сверху на карте — «Созвездие»: профиль сорта и пунктиром небо пользователя. Процент не показывается.
- Карта с совпадением от 90 % (`HOLO_THRESHOLD`) получает золотую подсветку и голографический слой.
- Все карты наклоняются в 3D вслед за курсором или пальцем.

## Заказ

На каждой карте колоды и в свитке сорта есть кнопка «Заказать». Она открывает форму
(`src/components/OrderModal.jsx`): сорт, фасовка, количество, имя, телефон, почта, доставка, адрес, комментарий
и согласие на обработку персональных данных.

Куда уходят заказы, задаётся в `.env` (пример — `.env.example`):

```
VITE_ORDER_ENDPOINT=https://example.com/api/orders
```

Форма отправляет туда POST с JSON заказа. Помимо контактов в заказе есть код и значения созвездия покупателя,
так что видно, какой вкус он собрал. Пока адрес не задан, форма работает в демо-режиме: заказ сохраняется
только в браузере посетителя, и он видит пометку об этом.

## Как подбирается чай

Для каждого сорта считается совпадение с созвездием пользователя: 72 % — схожесть формы профиля
(корреляция Пирсона: какие ноты выделяются), 28 % — близость по силе нот (RMSE).
Чтобы добавить сорт, допишите объект в `src/data/teas.js` — 12 чисел от 0 до 10 в порядке нот из `notes.js`.

## Каменная подложка

Диск под паутинкой — процедурная текстура «чёрного камня» (`src/assets/stone.avif` + запасной `stone.webp`).
Её можно перегенерировать с другим рисунком прожилок: `python3 tools/stone.py` (нужны numpy, scipy, Pillow ≥ 11.3),
меняя `seed`-числа в скрипте. Свой файл можно просто положить вместо `stone.avif`: квадрат с прозрачным фоном, диск по центру.
